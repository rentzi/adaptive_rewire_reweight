# Project description
This repository contains code, notebooks and selected data used for analysis in the preprint "Self-regulated emergence of heavy-tailed weight distributions in evolving complex network architectures". This study investigates how adaptive changes in connection weights and network topology can generate heavy-tailed connectivity patterns observed in biological neural networks. We examine how adaptive weight adjustment, alone and in combination with adaptive rewiring, shapes weight distributions and higher-order connectivity structure. 

Our results suggest that adaptive weight adjustment alone produces heavy-tailed weight distributions only under highly localized activity flow, whereas combining weight adjustment with adaptive  rewiring allows these distributions to emerge robustly across a broader range of activity regimes. The dual-adaptive model also produces convergent-divergent units, indicating that adaptive weight adjustment is compatible with the connectivity structure generated by adaptive rewiring. The model can account for key connectivity features of both the *C. elegans* and mouse retina datasets, suggesting that the underlying principles may be shared across species of varying complexity.

## `scripts/`
This folder contains reusable Python modules implementing the core functions used to generate networks, perform adaptive weight adjustment and rewiring procedures, conduct statistical analysis, compute connectivity metrics and generate figures.

## `HPC_scripts/`
This folder contains scripts used to run the Python code on a high-performance computing cluster. These scripts call the relevant Python scripts in `scripts/` and were used to generate simulation instances in parallel.

## `Basic analysis/` 
This folder contains notebooks and output for analysing networks generated to demonstrate model behavior.

- `0-Generate representative networks.ipynb`: generates a single instance for one representative parameter set to demonstrate the models.
- `1-Generate initial networks.ipynb`: generates the initial random networks for simulations.
- `2-Schema of dynamics.ipynb`: generates Fig 2 & S2 to illustrate the consensus and advection dynamics.
- `3-Statistical analysis.ipynb`: conducts statistical analysis and computes connectivity metrics.
- `4-Main figures in Results.ipynb`: generates Fig 4-8 to demonstrate model behaviors.
- `5-Supplementary figures for control conditions.ipynb`: generates Fig S3-S11 to demonstrate behavior of control conditions.
- `6-Supplementary figures for dual adaptive algorithm.ipynb`: generates Fig S12-S18 to demonstrate behavior of the dual-adaptive algorithm.
- `7-Supplementary figures for CD units.ipynb`: generates Fig S19-S24 to demonstrate the properties of convergent-divergent units in the simulated networks.
- `8-Supplementary note 1-Sensitivity analysis of learning rate.ipynb`: conducts sensitivity analysis of the learning rate in weight adjustment and generates Fig S26-S28.
- `9-Supplementary note 2-Sensitivity analysis of network density.ipynb`: conducts sensitivity analysis of network density and generates Fig S29-S32.
- `Output/`: contains initial networks, simulated networks at the last step of simulations, and processed data.
- `Output_long/`: contains simulated networks at several steps of simulations and processed data for stationary analysis.
- `Representative networks`: contains simulated networks generated by `0-Generate representative networks.ipynb`.

### General workflow

The typical workflow is:

1. Generate initial networks.
2. Run the simulation scripts in `HPC_scripts/` and store the generated simulation outputs in `Output/` and `Output_long/`.
3. Use the notebooks in `Basic analysis/` to load the data and reproduce the analyses and figures reported in the manuscript.


## `Fit to empirical connectomes/` 
This folder contains original data of two empirical connectomes and notebooks and output for analysing larger networks generated to fit empirical connectomes.

- `adjacency_adult.xml`: connectivity of the *C. elegans* nerve ring, Brittin et al. (2018), available from  [A multiscale brain map derived from whole-brain volumetric reconstructions](https://zenodo.org/records/4763083).
- `Mouse_retina.csv`: connectivity of the mouse retina, Helmstaedter et al. (2013), available from [ChrisWLynn/Heavy_tailed_connectivity](https://github.com/ChrisWLynn/Heavy_tailed_connectivity).
- `1-Clean data.ipynb`: generates adjacency matrices of two empirical connectomes from the original data.
- `2-Generate initial networks.ipynb`: generates initial networks that match the number of nodes and connections of empirical connectomes.
- `3-Statistical analysis.ipynb`: conducts statistical analysis and computes connectivity metrics.
- `4-Figures and tables.ipynb`: generates Fig 9, S25 and Table 1, S1.
- `Output/`: contains initial networks, simulated networks at the last step of simulations, and processed data.
- `Output_long/`: contains simulated networks at several steps of simulations and processed data for stationary analysis.

# Software Environment
The code requires Python 3.10 or newer and was tested using Python 3.10.9. Required Python packages are listed in `requirements.txt`. The exact tested environment is provided in `requirements-lock.txt`.

Create and activate a virtual environment, then install the dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```
